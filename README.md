# For The Masses

A round-based political mind game on Roblox where councilors persuade fictional city residents and investigate what happens to public projects.

## Run

Run `rojo serve` from this folder, connect to it from the Rojo Studio plugin, then press Play.

## Phased prompts

Each phase prompt can be pasted again at any point. Completed work is tracked in `PROGRESS.md` and git, so a prompt resumes at the first unfinished item.
